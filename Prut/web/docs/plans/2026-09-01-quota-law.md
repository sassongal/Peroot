## 1. העיקרון: מכסה היא נתון, במקום אחד, עם ברירת-מחדל אחת

השינוי הוא לא "לשנות 1 ל-2". זה יחזור להישבר. השינוי הוא להפוך את המכסה
לערך יחיד שכל שאר המערכת נגזרת ממנו:

```
          site_settings (ה-SoT)
     guest_daily_limit=1   daily_free_limit=2
                    |
       +------------+------------+
       |                         |
  שרת: quota-policy.ts      לקוח: useSiteSettings
  (ברירת-מחדל יחידה)        (ברירת-מחדל מאותו מודול)
       |                         |
  RPC · guest-service ·     PromptInput · Onboarding ·
  api/me/quota · signup ·   ResultSection · Settings ·
  webhooks · cron           QuotaExhaustedModal · pricing
```

שלושה כללים נגזרים, והם נאכפים בטסט:

- **אין מספר מכסה בקופי.** לא "2 שיפורים ביום", לא "קרדיט אחד ביום". המספר מוזרק.
- **אין `?? <מספר>` מחוץ ל-`quota-policy.ts`.** כל fallback מייבא משם.
- **גם מכסת האורח היא נתון.** `GUEST_DAILY_LIMIT` הופך לעמודה
  `site_settings.guest_daily_limit`, כך שגל יכול לשנות אותה מפאנל הניהול
  בלי דיפלוי, בדיוק כמו את מכסת הרשומים.

## 2. ביצוע

### 2.1 בסיס הנתונים (מיגרציה `20260901140000_quota_law.sql`)

- `ALTER TABLE site_settings ADD COLUMN IF NOT EXISTS guest_daily_limit INTEGER NOT NULL DEFAULT 1`.
- `UPDATE site_settings SET daily_free_limit = 2, guest_daily_limit = 1`.
- `handle_new_user()`: החלפת ה-4 הקשיח בקריאה ל-`daily_free_limit` (עם 2 כברירת-מחדל).
- `refresh_and_decrement_credits()`: ברירת-המחדל הפנימית נשארת 2, כלומר
  זהה ל-`QUOTA_FALLBACK.freeDaily`. הפונקציה עצמה כבר קוראת מהטבלה, לא נוגעים בלוגיקה.
- אידמפוטנטית, RLS נשארת דלוקה, מאומתת מול ה-DB החי אחרי ההרצה.

**אין אובדן נתונים:** רק הוספת עמודה ועדכון ערך. אף משתמש לא מאבד יתרה
(העלאת המכסה יכולה רק להיטיב עם יתרות קיימות, כי ה-reset מציב `v_balance := v_daily_limit`).

### 2.2 מודול המדיניות (`src/lib/quota-policy.ts`, חדש)

```ts
export const QUOTA_FALLBACK = { guestDaily: 1, freeDaily: 2 } as const;
export const PRO_MONTHLY_CREDITS = 150;
export function quotaPhrase(n: number): string   // "שיפור אחד ביום" / "2 שיפורים ביום"
export function creditsPhrase(n: number): string // "קרדיט אחד" / "2 קרדיטים"
```

הפונקציות העבריות קיימות כדי שהקופי יישאר תקין דקדוקית כשגל משנה את המספר:
"2 שיפורים" מול "שיפור אחד" הן צורות שונות, לא רק ספרה שונה.

### 2.3 קורא-שרת אחד (`src/lib/quota-server.ts`, חדש)

`getQuotaPolicy()` עם cache של 60 שניות: קריאה אחת ל-`site_settings`
שמחזירה `{ guestDaily, freeDaily }`, לשימוש קומפוננטות-שרת (pricing, FAQ, SEO).
