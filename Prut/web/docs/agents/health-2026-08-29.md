## Database (CRITICAL — fixed)
- **9 tables had no `CREATE TABLE` in `migrations/`** (5 nowhere, 4 in stray root
  `create-*.sql`): `credit_ledger`, `developer_api_keys`, `email_sequences`,
  `prompt_chains`, `prompt_versions`, `newsletter_subscribers`, `prompt_folders`,
  `referral_codes`, `referral_redemptions`. A clean rebuild would have failed.
  → `20260126000000_backfill_drifted_tables.sql` reconstructs all 9 from the live
  schema (idempotent, FK-ordered, RLS + indexes + policies), validated end-to-end
  in a rolled-back transaction. Stray root files deleted.
- Security posture otherwise solid: RLS on every table; every FK indexed;
  `capability_mode` enum in sync (VIDEO_GENERATION live).
- `supabase_schema.sql` marked non-authoritative (it is the bootstrap baseline;
  `migrations/` is canonical) and its stale `prompt_popularity` annotated.
